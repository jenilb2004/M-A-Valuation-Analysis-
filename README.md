# UltraTech Cement–India Cements M&A Valuation Analysis

A comprehensive M&A valuation project analyzing the potential acquisition of India Cements by UltraTech Cement. The project evaluates the financial feasibility and value creation potential of the transaction through integrated financial modeling and transaction analysis.

### Key Components

* Developed a 5-year financial model incorporating **DCF valuation, synergy forecasting, and pro forma financial statements** for the combined entity.
* Modeled revenue, COGS, and operating expense synergies to estimate the operational benefits of the acquisition.
* Evaluated multiple acquisition premium scenarios to assess their impact on transaction value and shareholder returns.
* Performed **EPS accretion/dilution analysis** and sensitivity analysis across different valuation and premium assumptions.
* Analyzed industry dynamics, transaction structure, and the long-term financial and operational implications of the acquisition.
